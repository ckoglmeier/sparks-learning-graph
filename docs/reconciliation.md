# Reconciliation with earlier work

## Earlier computing guidance

The 29 October contribution created eight teaching-research records for existing topics: precise instructions, algorithmic decisions/repeats, first visual programs, debugging, loops, nested loops, decisions/input, and concurrent events. It created no new topic IDs or prerequisite edges. The original files contain 67 source entries, 58 historically marked verified, with uncertainty and age extrapolations retained.

Current Marble already provides canonical v2 guidance for all eight IDs. We preserve that active guidance unchanged, and retain the original eight records under `supplements/computing-2026-10-29/` with hashes and explicit historical status. We neither discard the earlier work nor silently mix incompatible record formats. This is preservation, not renewed verification of all historical references.

The older snapshot's three IDs absent from current active topics are upstream-retired maths topics (unit relationships/conversion tables, telling time to the minute, decimal place value). They are not lost locally authored engineering additions. This release follows current upstream identities and does not resurrect them or perform consumer learner-state migrations.

Existing upstream claims sometimes bundle several requirements or use older age ranges. We preserve their meanings and document overlaps rather than silently narrowing them to make a new application appear aligned. The additions contain no product-specific course sequence.
