# Contributing

Search the complete existing claims before proposing a topic. One topic represents one assessable concept or operation; a new application, grade or tool name alone does not justify another node. Preserve IDs and unaffected records. Explain the evidence, countercase, transfer and reason for each prerequisite.

Keep new authoring within primary scope through age 12 unless explicitly agreed. Proposed teaching ages do not establish statutory alignment. Read official source meaning before mapping a curriculum code. Record component coverage, remaining requirements and explicit assessment exclusions; never convert an unmapped claim into a claim that every curriculum omits it.

Author scoped associations in `data/curriculum-alignments.json`. Flat ages and standards are derived compatibility fields. Keep canonical v2 research, stable activity/citation IDs, original authorship and evidence limits. Follow PROVENANCE.md; no restricted curriculum text, learner records or downloaded source papers.

For graph regeneration and the full curation suite, use the pinned upstream authoring tools linked in UPSTREAM.json. Those tools are not redistributed here. This release includes standalone schema, integrity and preservation checks; these do not regenerate derived artifacts. Refresh the release inventory with `python3 tools/refresh_manifest.py` after authorized edits, then run the checks in README.md and rebuild the archive. Never refresh a manifest merely to hide an unexplained mismatch.

Database contributions use ODbL 1.0; authored content uses CC BY-SA 4.0; original Python tools use MIT. State borrowed material and its license. Upstream collaboration is welcome but no endorsement or acceptance is implied by publication here.
