# Earlier computing guidance

These eight original records were authored on 29 October 2026 for existing topic IDs. They added teaching guidance, not topics or edges. They are retained unchanged as historical v1 supplements under CC BY-SA 4.0, with original AI authorship, source status and limitations.

Use `data/teaching-research.json` for current canonical v2 guidance. These supplements are not merged into those records and do not change mastery claims, dependencies, age scopes or curriculum mappings. Their historical verification flags have not been revalidated for this release; unverified references remain explicitly unverified. Some historical age bands extend beyond the current authoring scope. The record index binds each original file by SHA-256 and states its disposition.

The current upstream guidance is already populated for all eight IDs. Preserving the older material separately avoids silently replacing current records or losing earlier work. Source-specific observations, age extrapolations and proposed activities remain distinguishable in each file.
